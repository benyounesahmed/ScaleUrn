# ScaleUrn

ScaleUrn: A Cloud-Native, Autonomous Engine for Real-Time Processing and Auto-Scaling, built on a modular Framework.

ScaleUrn is built to be simple and practical, focusing on doing one thing well.

## Technology Stack

- javascript

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ScaleUrn.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

ScaleUrn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
